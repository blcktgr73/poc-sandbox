# poc-sandbox

`poc-sandbox` is a minimal repository for validating GitHub issue dispatch, agent pickup, and end-to-end delivery flow.

## Current purpose

- Confirm that a GitHub issue can trigger Morpheus work
- Leave a concrete repository change for the trigger issue
- Provide a clean place for future lightweight proofs of concept
